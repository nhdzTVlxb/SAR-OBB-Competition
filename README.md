# SAR-OBB-Competition

## 项目简介

本仓库为 **2025年全球校园人工智能算法精英大赛-算法挑战赛-大规模SAR图像多类别有向目标检测** 赛题的 **国一解决方案** 代码回顾。

本方案的核心思路是从 **数据特性** 和 **评估机制** 两个维度出发，解决比赛中的关键难点，最终取得优异成绩。

---

## 核心难点剖析

### 难点一：数据集的极端不均衡性

数据是本赛题最大的挑战，主要体现在两个方面：
1.  **类别分布极不平衡**：不同类别的实例数量差异巨大。
2.  **低识别度类别不稳定**：在不同模型框架下，表现较差的类别各不相同（例如，YOLO框架下 `haber` 和 `Bridge` 类别得分低，而MMLAB框架下 `Tank` 类别得分低）。

### 难点二：官方评分脚本的未知参数

官方提供的预测脚本（predict脚本）中包含 `conf_threshold=0.001`，`iou=0.75`，`max_det=600` 等参数。大多数选手可能会直接使用这些默认值，但并未深入思考这些参数的用途，也未探究官方后台评分时使用的具体参数设置。**这往往导致训练出的模型权重无法发挥其最佳性能。**

---

## 解决方案

针对以上两大难点，我们采取了以下针对性策略：

### 针对难点一：处理数据不均衡

我们采用了两种主要方法来缓解数据不均衡问题：

1.  **基于类别权重的加权采样器注入机制**
    *   **核心思想**：在训练过程中，通过自定义采样器，让模型在每轮迭代中更频繁地“看到”样本数量少的类别，从而平衡各类别的学习机会。
    *   **技术实现**：我们设计了一个 `SamplerInjector` 回调类。它在训练开始前动态地替换 `DataLoader`，实现基于类别权重的采样。
    *   **工作流程**：
        1.  训练开始前，获取原始数据集和 `DataLoader` 参数。
        2.  根据预设的 `weight_map` (各类别权重映射) 为每个样本计算采样权重（取该样本中所有类别权重的最大值）。
        3.  构建 `WeightedRandomSampler` (带放回的重采样)。
        4.  创建新的 `DataLoader` 并注入到训练器中。
    *   **关键优势**：
        *   **非侵入式**：通过回调机制注入，不修改 Ultralytics 等框架的源码。
        *   **灵活性高**：可动态调整各类别的采样权重。
        *   **处理空标注**：通过 `empty_label_weight` 参数避免无标注样本被完全丢弃。
        *   **统计反馈**：打印权重分布，便于监控和调优。

2.  **两阶段训练法**
    *   **第一阶段 (正常训练)**：运行 `train_org.py`，进行常规训练（例如 300 epoch）。此阶段的目标是得到一个基础模型，并观察不同类别（如 YOLO 下的 `haber` 和 `Bridge`）的表现差异，日志可参考 `log_org.txt`。
    *   **第二阶段 (精修微调)**：在第一阶段得到的权重基础上，运行 `V6.py` 进行微调。此阶段的核心思想和训练过程与第一阶段类似，但重点在于针对性地提升那些在基础模型中表现不佳的类别。

### 针对难点二：适配官方评分机制

我们对官方评分脚本的参数进行了深入分析和实验。结果表明，官方后台对预测框的质量有较高的容忍度。

*   **关键发现**：选手在预测时，如果自行设定较高的置信度阈值（`conf_threshold`）或交并比阈值（`iou`）来使预测结果“更干净”，反而可能会因为漏掉一些虽然置信度稍低但实际正确的检测框而**限制了自己的得分上限**。
*   **应对策略**：我们通过实验验证了官方参数设置下的评分容忍度，并在最终提交的预测脚本中采用了与官方评估逻辑相匹配的参数，确保模型的所有潜力都能被充分评估。

## 代码与日志说明

*   **`train.py`**：包含 **基于类别权重的加权采样器注入机制** 的训练脚本。
*   **`train_org.py`**：不包含采样器注入的正常训练脚本。
*   **`V6.py`**：进行第二阶段精修微调的训练脚本。
*   **`log_org.txt`**：正常训练过程的日志示例，可用于分析不同类别的收敛情况。
